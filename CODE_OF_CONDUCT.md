# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion focused on the work.
Harassment, discrimination, and personal attacks are not tolerated.

Report unacceptable behavior to the maintainer via a private GitHub message.
Reports are reviewed and handled confidentially.
